## Bienvenido

La API de Semántica permite integrar fácilmente las capacidades del ERP con aplicaciones externas mediante una interfaz moderna basada en REST. Está diseñada para que desarrolladores y sistemas externos puedan interactuar con la plataforma de forma segura, escalable y desacoplada.

Esta nueva capa de servicios ha sido desarrollada como una arquitectura no monolítica, permitiendo que diferentes aplicaciones —tanto internas como externas— consuman los servicios del ERP de manera eficiente.

La API está construida sobre FastAPI, proporcionando alto rendimiento, y un modelo de desarrollo moderno orientado a servicios.

La URL base es `https://semanticaapi.com.co`.

## Autenticación

Todos los endpoints (excepto `/auth/login` y `/auth/register`) requieren un Bearer token en el header `Authorization`.

### Obtener un token

Llama a `POST /auth/login` con tus credenciales:

```bash
curl -X POST https://semanticaapi.com.co/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "usuario@ejemplo.com", "password": "tu_contraseña"}'
```

Respuesta:

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

### Usar el token

Incluye el token en todas las peticiones posteriores:

```bash
curl https://semanticaapi.com.co/rhu/empleados/ \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

En el playground interactivo de cada endpoint, haz clic en **Authorize** e ingresa el token para probar los endpoints directamente desde el navegador.
